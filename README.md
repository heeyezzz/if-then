# 果然（If-Then）

> 应用名「果然」——如果……**果然**就……：提前订好的预案，在当下真的发生了。

一个个人用的 if-then 决策预案安卓 app，实践心理学中的 **implementation intentions**（执行意图）：提前写好「如果遇到 X，就执行 Y」，在诱惑/状态出现的当下不靠临场意志力，直接照案执行。

不是 Tasker 那类手机自动化，也不是 AI 工作流引擎——它管理的是**你和自己订的行为预案**。

## 核心循环

```
写预案 → 触发时一步打卡 → 晚上补记 → 复盘统计 → 修订预案库
```

- **手动打卡**：点「今天的现场」药丸一下即完成；卡片右滑也=完成（有音效和回弹动画）
- **卡片手势**：右滑完成 · 左滑露出「没做 / 移夹 / 归档 / 删除」圆钮 · 点卡片进编辑 · 展开后点空白或滚动列表自动归位
- **任务连锁**：在编辑页给一条预案指定「下一步接哪个预案」，就把几条串成一条线性链（A→B→C）。首页把同夹的链条成员聚成一组、左侧一条深绿竖线串起来、卡上标 ①②③；做完上一步后首页最上方浮现「▶ 下一步 · 接「X」之后」提示条（点=打卡，跳过=标没做并推进），整条做完换成 🎉 并响一段上行三音。中途「没做」只跳过、不断链；删掉中间节点会自动把前后接上
- **排序模式**：标题栏 ⇅ 进入，每张卡（含文件夹行）右侧出现 ①序号 + ▲▼⇈⇊，点一下移一格、长按箭头连续移动；链条成员跟着头部整体移动。每次点击即时落库，返回键先退出排序模式
- **文件夹**：点右侧箭头可在当前页行内展开该夹的预案（不跳页）；点整行才进入文件夹；长按改名/改外观/连带删除；跨夹的链条后继显示成 `↳ 在「夹名」` 角标
- **补记三态**：每条记录是 `做了 / 没做 / 待定`，复盘页可「补记触发」生成待定项，睡前翻流水补齐（补记只更新数据，不放音效和庆祝）
- **复盘闭环**：连击（连续顶住次数）、执行率、30 天热力图、最常触发（真实战场）、僵尸预案（两周没触发，建议归档）、链条健康（近 14 天走通几天、最常断在第几步）
- **AI 帮写**：描述困扰 → 模型出 3~5 条候选预案 → 人工勾选确认才入库（AI 不直接污染预案库）

## 界面

| 页面 | 内容 |
|---|---|
| 首页 | 「下一步」提示条 + 「今天的现场」高频药丸（按触发统计自动选前 6 条，点一下即打卡）+ 文件夹细行 + 当前层的预案卡片（链条聚合成组）+ 排序模式 |
| 复盘 | 今日流水、热力图、按文件夹分节的战绩汇总、僵尸预案、最常触发、链条健康、已归档 |
| 新建/编辑 | 如果…那就…、所在文件夹（下拉换夹）、下一步接哪个预案（建链/换接/取消）、归档/删除、AI 生成候选 |
| 设置 | AI 接口（BYOK）+ 测试连接、JSON 导出/导入 |

**文件夹**：可无限嵌套，每个夹可选 emoji 和颜色。左滑卡片点「移夹」在清单里直接选目标夹（含根目录），编辑页的「所在文件夹」也能换。长按文件夹卡片可改名/改外观/连带删除。

**链条**：只存一个 `nextRuleId` 指针，链条本身不是实体——名字借用头部预案的「如果」。禁止成环（候选清单直接过滤掉会造成环的节点），一个节点最多一个前驱一个后继，长度超过 8 步会提示建议拆链。

## 安装

到 [Releases](../../releases) 下载 `app-debug.apk`，手机上安装（允许未知来源）。

要求：Android 8.0+（minSdk 26）。数据全部存本地，AI 功能需要你自备一个 OpenAI 兼容接口（默认配置指向 DeepSeek）。

## 数据与隐私

- 所有预案和打卡记录存在设备本地（Room/SQLite），不经过任何服务器
- AI 生成候选时只把你输入的「困扰描述」发给 API，预案库不出门
- API Key 存 DataStore 私有目录，**不会**进入 JSON 导出文件
- 备份：设置页手动导出/导入 JSON（导入前会二次确认覆盖）

## 构建

```bash
# 需要 JDK 17 + Android SDK 35
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

技术栈：Kotlin · Jetpack Compose · Material 3 · Room · DataStore · OkHttp · kotlinx.serialization

## 已知未验证项

- SAF 文件选择器的导出/导入未在真机上手动验证（链条指针在导入时会重新做悬空清理和环检测，但这条路径只做过代码级检查）
- 数据库迁移 v1→v4（文件夹、sortOrder、nextRuleId）在模拟器上随真实升级安装验证过，真机旧数据未测

## 规则阈值

统计口径的调整参数集中在 [`Constants.kt`](app/src/main/java/com/ifthen/app/Constants.kt)：高频区条数、连击窗口、僵尸判定天数（默认 14）、热力图天数，按实际手感改。
